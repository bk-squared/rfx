### Fixed — realized_geometry() inside a JAX transform refuses and names the traced input instead of returning None (#2934)

`Simulation.realized_geometry()` called inside `jax.jacfwd`, `jax.grad` or `jax.jvp` while a
material value, a thin-conductor or lumped value, or a waveguide call override is traced
returned None, so a check against it was skipped without a word. It now raises `RfxRefusal`
naming each traced input, for example `material['name'].eps_r`; call it outside the transform
on concrete values. A second lookup in the same trace refuses the same way. `run()` and
`forward()` under the trace are unchanged.
