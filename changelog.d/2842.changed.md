### Changed — twenty top-level `rfx` modules state their conventions in docstrings instead of code comments (#2842)

- `rfx.auto_config`, `rfx.fidelity`, `rfx.grid`, `rfx.io`, `rfx.eigenmode` and fifteen smaller top-level modules
  have no code comments left other than tool directives. A convention the code cannot show is now one docstring
  sentence on the function, class or module it belongs to, so `help()` shows it: for example what
  `FeatureInfo.estimated_Q` holds, the mesh plane of a PMC face and the Touchstone format read when a file names
  none. The other comments were removed.
- No computation changes.
