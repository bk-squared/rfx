### Fixed — a float32 graded profile is admitted the same way traced or concrete (#1649)

- A `dx_profile` / `dy_profile` whose end cells equal the boundary `dx` to one float32 ULP (for example the profile
  cast to float32) is now accepted on the concrete path, as the traced path already did. Larger mismatches are still
  refused. No result changes for profiles that were accepted before.
