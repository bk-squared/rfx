### Fixed — default frequency bins no longer depend on a first run under jax.disable_jit (#2782)

- After a run under `jax.disable_jit()`, every later run in the same process used default DFT frequency bins up to 1 float32 ULP off (S up to about 15 ULP), so `run()` and `forward()` on equal requests could disagree in those last bits.
- The default bins are now the same whether or not the first run was under `disable_jit`.
