### BREAKING — a declared input that the lane running the model does not solve is now refused before the first time step, instead of solved as if absent (#1355)

- Each time-stepping lane (`run()` on a uniform, graded, subgridded, ADI or multi-device model; `forward()` on a uniform, graded, distributed graded or ADI model) now lists the inputs it carries. Any other declared input raises `NotImplementedError` naming the input and the lanes that do carry it.
- Declarations that ran before and now raise: under ADI, μr ≠ 1, Kerr χ³, `amplitude_kind='current'`, a PMC face, `cpml_kappa_max`, `interface_eps='dual_average'`, `precision` other than float32, a flux monitor and a microstrip port; on a graded mesh, Kerr χ³ (`run()`), a periodic axis, `cpml_kappa_max`, a Floquet port and `mode='2d_tmz'`; on the subgridded lane, a lossy thin conductor, a PMC face, a periodic axis, a microstrip port, a flux monitor and `interface_eps='dual_average'`, and with `validation='research'`/`'off'` also every input production validation refuses (dispersive poles, χ³, lumped RLC, CPML); on the uniform lane, a Floquet port scanned off normal, `interface_eps='dual_average'`, `Boundary(conformal=True)` together with a lumped-port S-matrix, and a flux monitor on `forward()`; on `forward(distributed=True)`, a microstrip port and an NTFF box.
- Each of these returned a result computed without the input. A model whose inputs are all carried runs exactly as before.
