### Added — checkpoint levels on the graded path (#9995)

`checkpoint_every` accepts a tuple of lengths on graded single-device runs, for any record length.
The planner and `estimate_ad_memory` report checkpoint levels and forward passes without changing forward results.
AD memory estimates read the fixed and per-cotangent working terms from the scene's compiled one-step pullback.
`cotangents` accounts for simultaneous pullbacks in estimates and checkpoint plans.
If compilation is unavailable, the estimate labels its per-cell fallback and zero working term.
These are memory estimates; GPU full-record accuracy requires measurement.
