Closed-box TF/SF plane waves now run across uniform device slabs in `run()`
and `forward(distributed=True)`, with the incident line replicated per device.
Unsupported open-slab, Method B, Bloch-line and face-record TF/SF sources,
waveguide ports, and all graded multi-device TF/SF sources now raise named
errors instead of warning and silently running the whole domain on one device.
