### Changed — multi-device runs apply the CPML absorber through the single-device kernel (#1724)

- `run(devices=...)` and `forward(distributed=True)` now update the CPML absorber with the same
  kernel as a one-device run; each device applies only the absorber faces it owns.
- On a uniform grid, two-device fields in a CPML box with a Debye-only or Lorentz-only block now
  match one device bit for bit over 800 steps; before, the Lorentz block differed by up to 25
  float32 ULP (macOS measurement).
- A block carrying both a Debye and a Lorentz pole still differs by up to 11.5 ULP at 800 steps on
  Linux; that difference starts in the two-pole update, not in the absorber (#1535).
