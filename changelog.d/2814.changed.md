### Changed — The float32 pole-strength gradient underflow warning is on by default (#2814)

- A float32 reverse-mode gradient with respect to a traced Lorentz or Drude pole strength in SI units now raises `AccuracyWarning` when its cotangent falls below float32's normal range (exactly zero on CPU). Before, the check ran only with `RFX_POLE_UNDERFLOW_CHECK=1`.
- `RFX_POLE_UNDERFLOW_CHECK=0` turns it off; set it before tracing, since a cached compile keeps its setting. Where the backend cannot run a host callback (mps, or a GPU process without a CPU device) the default leaves it off, and `1` is refused by name.
- Measured cost per traced call: the upper bound of the median on/off time ratio is at most 1.026 on CPU and 1.016 on GPU. Results are unchanged.
- Under `jax.vmap` the check makes one host call per call, not one per lane, and reports the total flagged count.
