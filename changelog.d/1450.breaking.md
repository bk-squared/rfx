### BREAKING — the API decisions before 2.0: three deprecated paths removed, Touchstone files in standard order, a wrong-gradient option refused, ADI CFL 2 (#1450)
- Replace `Simulation.set_periodic_axes` with `BoundarySpec` per-face periodic declarations.
- Replace `Simulation(pec_faces=...)` with `boundary=BoundarySpec(...)` PEC faces.
- Replace time-gated `minimize_s11_at_freq` with `minimize_s11_at_freq_wave_decomp` and `forward(port_s11_freqs=...)`.
- Touchstone writes and reads default to standard order; use `layout="legacy-rfx"` explicitly for old unmarked rfx files (default reads transpose legacy 3+ port matrices).
- `maximize_directivity(log_ratio=False)` now raises for wrong-sign power-changing gradients; use the default `log_ratio=True`.
- ADI defaults to CFL factor 2.0; pass `adi_cfl_factor=5.0` explicitly to retain the old timestep.
