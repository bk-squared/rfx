### Changed — twenty-seven modules of `rfx.probes`, `rfx.geometry` and `rfx.sparams` state their conventions in docstrings instead of code comments (#2919)

- Twenty-seven modules of `rfx.probes`, `rfx.geometry` and `rfx.sparams` have no code comments left other than tool
  directives. Some conventions the code cannot show now stand as one docstring sentence on the function, class or
  module they belong to, at most one each, so `help()` shows them: for example how a sample on a mesh face is
  classified, and that the MSL probe ladder comes back in increasing x for either port direction. The other
  comments were removed.
- No computation changes.
