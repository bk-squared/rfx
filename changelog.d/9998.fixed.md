Uniform meshes now realize the declared transverse absorbers for waveguide ports
smaller than the domain cross-section, matching the graded boundary rule.
Previously those faces reflected as electric walls; the measured error reached
2.9 dB in |S11| for an open-ended WR-90. These scenes now allocate the transverse
absorber cells. Full-aperture ports retain the undeclared electric-wall default
and its warning; explicitly declared incompatible guide boundaries still refuse.
