### Fixed — a float32 graded profile is admitted the same way traced or concrete (#1654)

- A `dx_profile` whose end cells equal the boundary `dx` to one float32 ULP (for example the profile cast to float32),
  or a `dy_profile` whose two end cells agree to one float32 ULP, is now accepted on the concrete path, as the traced
  path already did. Larger mismatches are still refused. No result changes for profiles that were accepted before.
