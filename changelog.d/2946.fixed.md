### Fixed — a current-moment monitor no longer builds Python objects per cell before the first step, so large monitors start (#2946)
- The measurement plan held one Python object per cell term of a current-moment monitor, an NTFF box and DFT and flux planes (about 38 kB per monitor cell) and built the moment and NTFF parts twice. A 97 x 97 x 20-cell monitor added 13.6 GB and 468 s to `run(n_steps=2)`, and a 32 GiB host could not start a run with about 460,000 monitor cells.
- The plan now holds them as arrays and its check compares them by content: the same monitor adds 0.27 GB and 7 s. NTFF boxes take 0.34 kB per face cell instead of 2.3 kB.
- Fields, moments, far-field data, DFT planes and flux are bit-identical to before on uniform and graded meshes, on one and several devices.
