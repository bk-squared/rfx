### Removed — Simulation drops the ADI factor keyword and rfx drops the ADI name redirects (#2886)

- `Simulation(adi_cfl_factor=...)` now raises `TypeError` for every value, including `None`; versions 2.1 and 2.2 refused every value except `None`.
- `rfx.ADIState2D`, `ADIState3D`, `thomas_solve`, `adi_step_2d`, `run_adi_2d`, `adi_step_3d` and `run_adi_3d` now raise Python's default `AttributeError` instead of the removal message.
- `rfx.model.admit_solver` now takes only `solver`. Saved 2.0 Yee design documents still load, and a saved ADI design is still refused by its solver value.
