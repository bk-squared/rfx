### Fixed — lumped/wire S with every port passive is refused instead of returned as each load's own reflection (#1929)

- With every lumped or wire port passive (`excite=False`), graded `run()` and uniform `forward(port_s11_freqs=)` returned each load's own reflection, about −60 dB whatever the structure, as `s_params`.
- A default request now warns and returns `s_params=None`; an explicit request raises. The per-port V, I and V_ref spectra stay in `lumped_port_sparams` / `wire_port_sparams` with `run(compute_s_params=False)`.
- Uniform `forward(port_s11_freqs=)` with a driven wire port and a passive lumped port now returns the driven wire's reflection (|S| near 1 on an open line) instead of the passive lumped port's load ratio (|S| about 0.02).
