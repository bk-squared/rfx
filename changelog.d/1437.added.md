### Added — `forward(gradient="adjoint")` takes far-field (NTFF) and H-plane objectives (#1437)

- A directivity or beam-pattern objective built with `compute_far_field` now gets the adjoint gradient on the
  uniform lane: on an RTX A6000, 2.1x a forward run at 6e5 cells (`jax.grad`: 2.6x) and 1.7x at 3.7e7 cells,
  where `jax.grad` runs out of memory on 48 GB. Memory does not grow with the record.
- H DFT-plane objectives are accepted too. The gradient is still the settled-spectrum gradient; check
  `ForwardResult.adjoint_settling`. Design conductivity stays refused.
- `scripts/benchmarks/adjoint_vs_autodiff.py --ntff` reproduces the comparison.
