### Changed — rfx 2.0.0rc1, the first release candidate of 2.0 (#1436)

- The 2.0 release candidate was published as `2.0.0rc1` (`pip install --pre rfx-fdtd`); plain `pip install rfx-fdtd` kept resolving to the latest stable release.
- The README states what 2.0 changes for a user: unimplemented inputs are refused, results are judged by the stated accuracy bar, Python 3.11 or newer is required, and multi-device execution is planned for 2.1.
