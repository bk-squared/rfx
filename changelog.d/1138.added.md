### Added — mesh lines that follow conductor sheet edges: `rfx.mesh_edges.edge_aware_profile` (#1138)

- A PEC sheet is solved as if it ended about 0.3 cell beyond its last PEC node
  (measured +0.29 … +0.32 cell, both polarizations, two cell sizes; a flat PEC
  wall has no such offset). `edge_aware_profile` builds a `dx_profile` /
  `dy_profile` with a node 0.3 cell INSIDE every sheet edge and a node ON every
  face — the measured counterpart of the openEMS thirds rule.
- On the 2-D fin it was measured on, the frequency error against a fine-mesh
  reference over 17 drawn lengths goes from rms 1.18 % (max 2.39 %) on the
  uniform 1 mm grid to rms 0.10 % (max 0.22 %); a 3-D patch's three strongest
  modes move 0.17 / 0.21 / 0.28 % when the in-plane cell is halved, against
  0.75 / 2.14 / 1.10 % on the uniform grid.
- `fidelity_report()` no longer tells the user to put a mesh node ON a sheet's
  edge; for sheets its remedy now names this function.
