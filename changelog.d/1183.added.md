### Added — the design-box gradient tape now reaches the graded mesh and a traced PEC occupancy (#1183)

- `forward(design_box=..., design_eps_override=...)` runs on the non-uniform
  lane. The corners resolve against the graded grid's own cell edges and the
  box redo uses the graded curl (`update_e_box(inv_d=...)` → `curl_h_nu`), so
  a thin substrate meshed with a `dz_profile` gets the same box-shaped
  reverse-mode tape the uniform lane got in #1179. Measured on the lane's own
  kernels, 25×25×25 cells over 200 steps with a 4×4×4 box: saved residuals
  124.44 MB → 1.06 MB, largest saved array `f32[200,25,25,25]` → `f32[25,25,25]`
  (no per-step history of the grid at all), `value_and_grad` 178 ms → 104 ms.
- `forward(design_box=..., design_occupancy_override=...)` differentiates a
  relaxed-conductor OCCUPANCY in one box — metal-shape design rather than a
  dielectric one. The `1 - M` scaling is redone on the box plus one cell (the
  reach of the incident-cell rule) from the field before the grid-wide
  `apply_pec_occupancy`, and `1 - M` is built once outside the time loop
  because an occupancy is a design variable and not a field. 23×21×19 cells
  over 200 steps with a 3×3×3 box: 23.22 MB → 0.70 MB, largest saved array
  `f32[200,23,21,19]` → `f32[200,4,4,4]`. It composes with a static
  `pec_occupancy_override`, replacing it at the box cells and carrying it
  everywhere else.
- Same gradient on both, not an approximation: float64 agreement with the
  whole-grid formulation is 1.3e-15 on the graded-mesh step loop and 5.3e-16
  through `forward` for the occupancy (3.1e-16 composed with a static
  occupancy). The non-uniform runner stores float32 fields whatever
  `precision` asks for (#630), so the end-to-end graded-mesh comparison is
  gated against that lane's own float32 rounding instead.
- `rfx.simulation.run` gains `design_occupancy`;
  `rfx.runners.nonuniform.run_nonuniform_path`, `rfx.nonuniform.run_nonuniform`
  and `run_nonuniform_until_decay` gain `design_box`. `update_e_nu` now builds
  its `Ca`/`Cb` through the shared `e_update_coeffs`, byte-identically.
- Fenced, never silently dropped: on the graded mesh a waveguide port, an MSL
  port and `until_decay` raise, and the shared resolver's fences (absorber,
  source / wire-port / RLC cell, dispersion, subpixel eps, a sheet in the box)
  apply there as they do on the uniform lane. The design occupancy is uniform
  single-device only and refuses a periodic axis and a design permittivity in
  the same call; the GPU baked-coefficient fast path excludes it, as it
  already excludes the permittivity box.
