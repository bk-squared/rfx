### Fixed — On the graded mesh, a plane wave at 0 < |angle_deg| <= 0.01° over a structure finite along the tilt axis is refused as at 0°, instead of running unchecked (#2720)

The source realizes |angle_deg| <= 0.01° as normal incidence. The graded-mesh admission
still treated these angles as oblique and skipped the invariance check along y (`ez`) or
z (`ey`), so a structure finite along that axis ran without the check that refuses it at
0° (a plane wave on the graded mesh holds only for a structure uniform along y and z).
It is now refused with the message and remedy given at 0°. On the uniform mesh these
angles now give the 0° refusal text and remedy. `compute_rcs` also treats them as normal
incidence; before, above 1e-6° it took its oblique route, which refuses `ey`, graded grids
and targets that vary along z. Scenes admitted before run unchanged.
