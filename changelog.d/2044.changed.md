### Changed — settling witnesses identify long windows with a partial SVD (#2044)

- Every settling witness uses partial SVD identification. WR-90-class windows
  are no longer refused by the 4 GiB identification bound when the partial
  method certifies; an unresolved identification uses the full SVD if it fits.
- Ring-down completion in `run(ringdown=)` and `forward(ringdown=)` still
  refuses those windows before the run, as before.
