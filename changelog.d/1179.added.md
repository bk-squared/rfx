### Added — a design region's permittivity is differentiable without putting the whole grid on the AD tape (#1179)

- `Simulation.forward(design_box=..., design_eps_override=...)` takes the design
  permittivity for one static box, in metres, instead of writing it into a
  whole-grid `eps_override`. The Yee E update `E <- Ca·E + Cb·curl(H)` is linear
  in the fields, so the backward recursion needs the primal field only where a
  coefficient is a design variable: with the grid-wide coefficients left
  constant and the box alone recomputed, reverse-mode AD stores box-shaped
  arrays per timestep where `eps_override` stores grid-shaped ones. Measured on
  a 23x21x19 open-domain fixture with a 3x3x3 design box, the tape grows by 652
  bytes per timestep instead of 431,300 — 0.018 of a float32 grid array per step
  against 11.7. On a 37x37x29 grid over 400 steps that is 3.2 MB against
  745.1 MB, and 3.2 MB against 37.7 MB for `checkpoint_segments=20`, which the
  box needs neither of: it recomputes nothing and ran 1.1-1.7x faster than
  either on CPU.
- Pass `checkpoint=False` with it. `forward()`'s default per-step remat saves
  the scan carry — six grid-sized field arrays — once per step whatever the
  coefficients are, so it hides most of the saving: 0.59 MB of residuals
  against 26.2 MB on a 23x21x19 grid over 80 steps.
- The gradient is the same gradient, not an approximation: it agrees with the
  `eps_override` path to 8e-16 relative in float64, and the forward value to
  1.5e-16 (`tests/unit/autodiff/test_design_box_tape.py`).
- `design_sigma_override=` makes a conductive design region differentiable on
  the same footing; left out, the box keeps the conductivity the run already
  declared there.
- Every combination the box does not carry RAISES rather than dropping the
  design variable to a zero gradient: non-uniform mesh, `distributed=True`,
  `solver='adi'`, `boundary='upml'`, Debye/Lorentz dispersion, Kerr,
  subpixel/anisotropic permittivity, `pec_occupancy_override`,
  `stencil_order=4`, the oblique-periodic Bloch path, combining with
  `eps_override`/`sigma_override`/`mu_r_override`, a box reaching into the CPML
  absorber, and a box holding a source, port, lumped-RLC or
  surface-impedance-sheet cell.
