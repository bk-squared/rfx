# Retirement of the unused stage-6 voltage prototype

2026-09-11. Audit against main `f990f9a05c2150c2265fd8d47af820792a05e58e`.
This takes #794's explicit option to delete an unused diagnostic copy.

`scripts/diagnostics/patch_edgefed_stage6_voltage_deembed.py` contained both
`_V_from_plane` and an inlined equivalent in `run_feed_and_probe`. Both
integrated the upper bounding node's normal edge as part of the substrate.
Deleting only the unused named helper would have left the executed copy.
The whole standalone prototype is retired.

Searches of the tracked tree for the filename, its former
`issue80_stage6_voltage_deembed.py` name, fitting helper, stage identifier
and distinctive output strings found no code/configuration caller or
published result consumer. The sole filename reference is the historical
#514 follow-up in the tagged 1.7.0 changelog; that record is preserved.
The original workspace's scripts, docs and package configuration likewise
contain no filename reference. No running Python process named this script
was found during the audit.

The script printed to stdout and read optional
`/tmp/patch_edgefed_stage1b_*.npz` reference inputs. It had no result-file
writer. Its introduction commit,
`3c24b6a1205ee706ea452daaf3ac03a58119bb6b`, says its evidence dumps were
local-only. No corresponding tracked stage-6 result artifact was found.
No local research data is removed or regenerated by this retirement.

**Historical numerical reports are pre-fix, not current validation.** The
introduction commit reports short magnitude about 1.000, phase error 3–4
degrees, residual about 2.5e-14, patch magnitude 0.93–0.96 against a 0.47
reference, a 0.49 finite-span VSWR reading, and a probe phase span about
84 degrees. These all belong to that prototype and its inclusive voltage
integral. They are neither re-derived nor endorsed here; its claimed
interpretation is not used to establish present physics accuracy. The
original commit and subsequent rename `91e95c83` remain in Git history.

The retained primitive is `rfx.api._sparams.msl_modal_voltage`. Existing
always-on tests independently specify the half-open edge integral, reject
influence from the trace-plane edge, and cover per-cell spacing. Existing
plane-diagnostic parity tests compare against production on identical
synthetic field planes, on aligned and bisecting meshes. Those are the
relevant retained numerical checks; deletion leaves no stage-6 adapter to
compare or new calculation to qualify. No new FDTD experiment is needed.

Verification: both named test files passed, 32 tests total. The log is
`issue794-retained-voltage-contracts.log.gz`; uncompressed SHA-256 is
`c155ef339188665973d43de4348d1be479ffcbb26deaad8b29e532a89f423890`. Diff whitespace checks passed.
