The MSL replay fixtures (`tests/fixtures/msl_replay_accumulators.npz`,
`tests/fixtures/msl_replay_golden_f64.npy`) cannot be recaptured until this
script draws the board the way the rest of the tree now does. It is the only
change needed; the rest of the script is unaffected.

## What is wrong today

Lines 33-40 and 69-73:

```python
H_SUB = 254e-6
DX = 80e-6
...
    sim.add(
        Box((0.0, trace_y_lo, H_SUB), (LX, trace_y_hi, H_SUB + DX)),
        material="pec",
    )
```

Two things, both fixed by the lattice ownership contract rather than worked
around:

1. `H_SUB + DX` is a **volume** declaration under §1.2. The trace is 35 µm
   copper foil; realized as a volume it becomes an 80 µm slab with tangential
   walls on both z faces and the Ez edge between them shorted.
2. `H_SUB / DX = 254 / 80 = 3.175`, so no node sits on the laminate face. A
   sheet declared at `H_SUB` on this mesh snaps to node 3 (240 µm), buried
   inside a dielectric the same mesh realizes 320 µm thick, and the assembly
   warns. Design note §1.3: the fixtures are redrawn **on-lattice**.

## Replacement

```python
EPS_R = 3.66
H_SUB = 254e-6
W_TRACE = 600e-6
L_LINE = 10e-3
PORT_MARGIN = 2e-3
# ON-LATTICE board (#931 §1.3): h_sub / dx = 3 exactly, so the laminate face
# IS a node line and the foil sheet below lands on it with no snap. This
# mirrors tests/unit/sparams/test_msl_port_integration.py, which the fixture
# is a replay of; it ran at dx = 80 µm (h_sub/dx = 3.175) until the contract.
DX = H_SUB / 3
F_MAX = 5e9
```

and

```python
    # 35 µm copper foil: a SHEET (#931 §1.3), declared by a zero-thickness Box
    # on the laminate face. Realized as ONE wall plane with the normal Ez left
    # live. One cell thick it is a VOLUME — walls at both z faces and the Ez
    # between them shorted, i.e. 85 µm of solid metal.
    sim.add(
        Box((0.0, trace_y_lo, H_SUB), (LX, trace_y_hi, H_SUB)),
        material="pec",
    )
```

## After the edit

The two fixtures are regenerated by the script's own documented command,
`python scripts/capture_msl_replay_fixture.py`, ~10 min on CPU. Their consumer
is `tests/unit/autodiff/test_msl_sparam_ad.py` (group T1), whose numbers move
with the board — the recapture and that file's re-pin belong in one commit,
with the pre-#931 files kept beside the new ones as history.
