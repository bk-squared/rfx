## Make your first simulation

Start with [installation](/rfx/guide/installation/) and the
[first runnable model](/rfx/guide/first-run/), then follow the
[visual manual](/rfx/guide/visual-manual/) from model to field to measurement.
The [Examples hub](/rfx/examples/) links to runnable source and a learning path.

```bash
pip install rfx-fdtd
```

The published package and these development documents may describe different
revisions. Match your installed version to the source/version shown by the site,
and read [migration notes](/rfx/guide/migration/) before adapting an older example.

## Choose a supported model

Uniform Cartesian Yee FDTD on one device is the starting point for the manual.
Port calculators, graded meshes, dispersive materials and differentiable objectives
each have specific supported combinations. Use
[Support Boundaries](/rfx/api/support-boundaries/) before combining them and
[Accuracy & validation](/rfx/validation/) before reporting an RF result.
See also the versioned [known limitations](https://github.com/bk-squared/rfx/blob/a9054338616b91bb1364699882c2530fa29a0048/docs/guides/known_limitations.md).

Looking up a call? Start at the [API](/rfx/api/). Working with an assistant?
Use the [machine-readable documentation index](/rfx/llms.txt), generated from the
same documentation snapshot.
