Start with a physical question, build a model, and decide what you will measure.
The [visual manual](/rfx/guide/visual-manual/) shows that sequence with fields,
structures and response curves.

New here? Read [Installation](/rfx/guide/installation/),
[first runnable model](/rfx/guide/first-run/), [Quick Start](/rfx/guide/quickstart/),
then [Core Concepts](/rfx/guide/concepts/):
cells, boundaries, conductors, sources and ports, and when a run is finished.

| Your next step | Read or run |
|---|---|
| See what rfx can simulate | [Visual examples](/rfx/gallery/) |
| Choose a material and draw a structure | [Materials & geometry](/rfx/guide/materials-geometry/) |
| Excite the model | [Sources & ports](/rfx/guide/sources-ports/) |
| Inspect fields and export plots | [Visualization & analysis](/rfx/guide/visualization-and-analysis/) |
| Measure reflection and transmission | [Probes & S-parameters](/rfx/guide/probes-sparams/) |
| Build a real device | [Your First Patch Antenna](/rfx/guide/first-patch/) |
| Refine the mesh and check the answer | [Convergence study](/rfx/guide/tutorial-convergence/) |
| Change a design using derivatives | [Inverse design](/rfx/guide/inverse-design/) and [gradient behavior](/rfx/guide/gradient-behavior/) |

Use the [Examples hub](/rfx/examples/) to choose by structure or follow the
ordered source tutorials. Check [Support Boundaries](/rfx/api/support-boundaries/)
for combinations of ports, materials, grids and runners; the [API](/rfx/api/)
gives the exact calls.
