`rfx` is a JAX-based, differentiable 3-D FDTD simulator for RF and microwave
engineering.

New here? Read these in order:

1. [Installation](/rfx/guide/installation/): install and check the setup.
2. [Quick Start](/rfx/guide/quickstart/): the six steps of every rfx model.
3. [Core Concepts](/rfx/guide/concepts/): cells, boundaries, conductors,
   sources and ports, and when a run is finished.
4. [Your First Patch Antenna](/rfx/guide/first-patch/): a real device.

The full topic index is on the [documentation home](/rfx/). The
[Support Boundaries](/rfx/api/support-boundaries/) page says which feature
combinations are supported.

Source code: [bk-squared/rfx](https://github.com/bk-squared/rfx).
