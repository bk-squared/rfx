## Read a reference comparison

The earlier [dielectric-slab gallery](/rfx/gallery/multilayer_fresnel/) and
[empty rectangular-waveguide gallery](/rfx/gallery/waveguide_wr90/) retain their
field, response and derivative artifacts. Both bundles were computed with
rfx 1.6.5 at `1eb551b`. Conductor placement and absorber behavior have changed
since that version, so their recorded results are not current-version benchmarks.
Read each page's precise limits and measurement definitions.

The [patch-antenna diagnostic archive](/rfx/gallery/patch_antenna/) is preserved
for traceability. Its stored port setup does not pass current preflight; it is
not a validated antenna showcase.
