title: "Tune a microstrip notch"
description: "Connect an open-stub length to a design trajectory and inspect its frequency-domain electric field."
---

A short open-ended branch attached to a microstrip line acts as a resonant stub.
Changing its length changes the frequencies that pass through the line. It is a
compact way to connect a geometric design variable, a frequency response and a
local field pattern.

<p data-rfx="note"><strong>Historical visualization.</strong> The design-path and field films use different stub lengths. They illustrate the same structure family, not one jointly reproduced result.</p>

## Read the model

| Part | Meaning |
|---|---|
| Structure | A planar microstrip line with an open-ended side branch |
| Materials | Conducting trace and ground with a dielectric substrate |
| Design variable | The open-stub length |
| Measured response | Transmission through the line, S21, over frequency |
| Field panel | A normalized E<sub>z</sub> slice at one frequency |

The field movie uses a 7.22 mm stub. The final spectrum associated with the
archived design path uses 7.14 mm. The field panel therefore explains the local
mechanism without certifying the final design-path spectrum.

## Explore the related source

The versioned [notch research example](https://github.com/bk-squared/rfx/blob/a9054338616b91bb1364699882c2530fa29a0048/validation/tmtt_paper/msl_stub_notch_tuning.py)
contains the model and design objective. It is a full multi-start research
workload: unlike the taper example, it has no short `SMOKE=1` mode.
Read its [run notes](https://github.com/bk-squared/rfx/blob/a9054338616b91bb1364699882c2530fa29a0048/validation/tmtt_paper/README.md)
before executing it from a matching source checkout:

```bash
JAX_PLATFORMS=cpu PYTHONPATH=. python validation/tmtt_paper/msl_stub_notch_tuning.py
```

For a smaller first exercise, use
[Ports and S-Parameters 101](https://github.com/bk-squared/rfx/blob/a9054338616b91bb1364699882c2530fa29a0048/examples/tutorials/ports_and_sparams_101.py).
Keep the excitation, port calculator and reference planes with any new response.

**Try changing:** the stub length. Track where the transmission minimum moves
across the band, and inspect the full curve rather than a single frequency bin.
