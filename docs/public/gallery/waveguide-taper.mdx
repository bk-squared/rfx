A guided wave meets a higher-permittivity dielectric load. A transition made of
short dielectric sections gives the wave a gradual change of environment. This
example asks how the section permittivities change the reflected-wave spectrum.

## Read the model

| Part | Meaning |
|---|---|
| Guide | A rectangular metal-walled guide with absorbing ends along propagation |
| Load | A dielectric-filled continuation of the guide |
| Design | A sequence of dielectric sections ahead of the load |
| Excitation and measurement | The guided mode and its reflected port response |
| Objective | Band-averaged reflected power |

The current [research source](https://github.com/bk-squared/rfx/blob/a9054338616b91bb1364699882c2530fa29a0048/validation/tmtt_paper/waveguide_dielectric_taper.py)
distinguishes its geometries: the short CPU setup realizes WR-90 dimensions,
while the paper meshes realize a 23 mm broad wall rather than the nominal
22.86 mm. Its reported paper responses belong to those realized guides.
The legacy [empty-guide example](/rfx/gallery/waveguide_wr90/) is a different model.

## Run the related example

In a source checkout matching the linked revision, install the project's example
dependencies and run its documented CPU setup:

```bash
python -m pip install -e ".[optimization]"
SMOKE=1 JAX_PLATFORMS=cpu PYTHONPATH=. python validation/tmtt_paper/waveguide_dielectric_taper.py
```

This short run produces an initial/optimized response and material-profile figure.
It exercises the workflow; it does not reproduce these archived movies or the
full-resolution paper result. Read its preflight output and realized dimensions.

**Try changing:** the initial permittivity profile or number of sections. Compare
the complete reflection curve and keep the guide, ports and frequency band fixed.
See [Waveguide Ports](/rfx/guide/waveguide-ports/) and
[Inverse Design](/rfx/guide/inverse-design/) for the API path.
