This page shows how to excite a model. A **source** injects a field and has no
impedance. A **port** also terminates the line in a known impedance, so rfx can
compute S-parameters from it. [Core Concepts](/rfx/start/concepts/#sources-and-ports)
explains the difference.

Each port family has its own S-parameter calculator. Only that calculator
gives S-parameters for it:

| Structure | Port | Calculator |
|---|---|---|
| discrete feed, component terminals | `add_port(...)` (lumped; with `extent=` a wire port) | `run(compute_s_params=True)`, or `forward(port_s11_freqs=...)` for gradients |
| microstrip line | `add_msl_port(...)` | `compute_msl_s_matrix()` |
| rectangular waveguide | `add_waveguide_port(...)` | `compute_waveguide_s_matrix()` |
| coaxial line | `add_coaxial_port(...)` | experimental uniform `run()` / `forward()`; `compute_coaxial_line_reflection()`, `compute_coaxial_two_port()` |

Each calculator takes one port family, apart from two that join families:
`compute_mixed_s_matrix()` (lumped or wire plus microstrip) is experimental,
and `compute_coax_msl_transition()` is deprecated (see [Limits](#limits)). If
you are not sure which calculator a model needs, `sim.s_matrix_lane()` tells
you without running anything, and `sim.compute_s_matrix(**kwargs)` calls it
for you. `compute_s_matrix` refuses a model with only lumped or wire ports: call
`run(compute_s_params=True)` for those.

## Waveforms

Point sources and lumped/wire ports take a waveform object. Waveguide ports
take `f0` and `bandwidth` as arguments and accept only
`waveform="modulated_gaussian"`. TFSF sources take `f0` and `bandwidth` and
name their pulse with a string (`"differentiated_gaussian"`,
`"modulated_gaussian"` or `"continuous_wave"`), or take a `CustomWaveform`.

```python
import jax.numpy as jnp
from rfx import CustomWaveform, CWSource, GaussianPulse, ModulatedGaussian

pulse = GaussianPulse(f0=2.4e9, bandwidth=0.5)       # broadband, no carrier
burst = ModulatedGaussian(f0=3e9, bandwidth=0.6)     # carrier with a Gaussian envelope
cw = CWSource(f0=5.8e9, ramp_steps=50)               # sinusoid, tapered on over 50 cycles

def chirp(t):
    rate = (4e9 - 1e9) / 10e-9
    return jnp.sin(2 * jnp.pi * (1e9 * t + 0.5 * rate * t**2))

sweep = CustomWaveform(func=chirp)                   # any JAX-traceable f(t)
```

| Waveform | Spectrum | Use it for |
|---|---|---|
| `GaussianPulse` | differentiated Gaussian; broad, extends well below `f0` | the default; broadband S-parameters |
| `ModulatedGaussian` | Gaussian centred on `f0`, width `f0·bandwidth` | a band away from DC; resonance searches |
| `CWSource` | one frequency | steady-state field pictures |
| `CustomWaveform` | whatever `func` gives | chirps, measured drive signals |

`bandwidth` is fractional. When you omit `waveform`, rfx uses
`GaussianPulse(f0=freq_max/2, bandwidth=0.8)`.

`GaussianPulse` starts from zero and its time integral is zero, so a soft
source driven by it leaves no static field behind. Its `cutoff` (the number of
`tau` before the peak) must be at least 2.5.

## Point sources

`add_source` is a soft source at one grid edge. It does not load the
structure, so a cavity's Q is unchanged. Use it for resonances, field
patterns and far fields.

```python
from rfx import Box, Simulation

sim = Simulation(freq_max=6e9, domain=(0.05, 0.05, 0.02), dx=2.5e-3,
                 boundary="cpml", cpml_layers=6)
sim.add_material("substrate", eps_r=3.2, sigma=0.01)
sim.add(Box((0.010, 0.010, 0.005), (0.040, 0.040, 0.015)), material="substrate")

sim.add_source((0.025, 0.025, 0.010), "ez",
               waveform=GaussianPulse(f0=3e9), amplitude_kind="current")
```

Always pass `amplitude_kind`:

- `"current"`: the waveform's amplitude (its `amplitude`, or the value a
  `CustomWaveform` returns) is a current moment in A·m, a source strength
  that does not refer to the cell. Use this by default.
- `"field"`: the waveform's amplitude is added to E each step, in V/m.

Omitting it or passing `None` selects `"current"` and warns once per simulation.
`tests/unit/sources/test_source_amplitude_kind.py` checks that omitting the kind
gives the same record as `"current"`, bit for bit, on a closed and an open
uniform mesh and on a graded mesh, and that `"current"` gives the
same probe record on a uniform and a graded mesh of equal cells (scale within
1×10⁻⁵). How the injected power changes when you refine the mesh has not been
measured.

### Polarized sources

`add_polarized_source` drives two components together:

```python
sim.add_polarized_source((0.025, 0.025, 0.010), polarization="slant45",
                         amplitude_kind="current")
sim.add_polarized_source((0.025, 0.025, 0.010), polarization=(1.0, -0.5),
                         waveform=GaussianPulse(f0=3e9), amplitude_kind="current")
```

`"ex"`, `"ey"`, `"ez"`, `"slant45"` and real `(Ex, Ey)` tuples give linear
polarization. `"circular"`, `"rhcp"`, `"lhcp"` and complex tuples are accepted,
but their time-domain phasing has not been verified. Do not rely on them for
axial ratio or handedness.

## Plane waves (TFSF)

`add_tfsf_source` launches a plane wave inside a total-field region, for
scattering and RCS. It travels along x (`"+x"` or `"-x"`) with `"ez"` or `"ey"`
polarization, and needs CPML on the two x faces; UPML is refused. By default
the plane wave fills the whole y-z cross-section. `closed_box=True` builds a
finite total-field box instead and needs `boundary="cpml"` on all six faces.

```python
scatter = Simulation(freq_max=8e9, domain=(0.06, 0.06, 0.06), dx=3e-3,
                     boundary="cpml", cpml_layers=6)
scatter.add_tfsf_source(f0=5e9, bandwidth=0.4, polarization="ez",
                        direction="+x")
```

For oblique incidence, set `angle_deg` and choose `method`:

- `method="bloch"` (default): a periodic unit cell, for infinite arrays and
  surfaces. Its fields are complex, and frequency monitors do not account for
  that.
- `method="methodB"`: an open domain around a compact scatterer. It needs
  `polarization="ez"`, `direction="+x"` and a uniform grid.

With `waveform=None` (the default), the pulse depends on the launch: a
differentiated Gaussian at normal incidence, with `closed_box=True` and with
method B, and a modulated Gaussian for oblique Bloch. Method B honours the declared pulse and bandwidth. Explicit
`waveform="differentiated_gaussian"` on oblique Bloch is refused: its fixed
transverse wavenumber is right only near `f0`, so it can carry only a
modulated Gaussian centred on `f0`. Declare
`waveform="modulated_gaussian"`, leave it unset, or use `method="methodB"`
for an open domain. Every modulated Gaussian peaks at t0 = 5τ, oblique Bloch included.

TFSF cannot share a simulation with any port, and `add_tfsf_source` also
refuses when a point source is already declared. It is not a port and gives no
S-parameters. For RCS, see [Far-Field and RCS](/rfx/measure/far-field-and-rcs/).

## Lumped and wire ports

`add_port` is a feed with a resistive load equal to `impedance`. It is the
port to use for a discrete feed, a probe feed, or a component's terminals.

- Without `extent`, it is a **lumped port**: one cell.
- With `extent`, it is a **wire port** that spans `extent` metres along its
  component axis, from `position` to `position + extent`. Use it to bridge a
  gap between two conductors, such as a probe feed through a substrate.
- `radius=` declares the wire port's probe-pin radius, within the local
  thin-probe mesh restrictions. If omitted, the effective pin radius follows
  the mesh and its series inductance changes under refinement.

```python
sim = Simulation(freq_max=6e9, domain=(0.05, 0.05, 0.02), dx=2.5e-3,
                 boundary="cpml", cpml_layers=6)
sim.add_port((0.01, 0.025, 0.010), "ez", impedance=50.0,
             waveform=GaussianPulse(f0=3e9))
sim.add_port((0.04, 0.025, 0.010), "ez", impedance=50.0,
             waveform=GaussianPulse(f0=3e9))

result = sim.run(n_steps=300, compute_s_params=True,
                 s_param_freqs=jnp.linspace(1e9, 5e9, 21))
s11 = result.s_params[0, 0, :]    # S[receiver, driven, freq], complex
s21 = result.s_params[1, 0, :]
```

With several ports, rfx drives each in turn and assembles the full matrix.
All ports in one calculation must be lumped, or all wire. Without
`s_param_freqs`, rfx uses 50 points from `freq_max/10` to `freq_max`. The run
above is far too short to settle; it only shows the calls.
[Probes and S-Parameters](/rfx/measure/s-parameters/) covers plotting and
Touchstone export.

### Getting accurate S11

- **Resolve the wavelength.** Start from about **60 cells per wavelength** at
  the highest frequency you care about. No current test measures the accuracy
  at that resolution; a mesh series decides it
  ([Is the mesh fine enough?](/rfx/check/mesh-convergence/)).
- **Know the reference plane.** A one-cell port reads its voltage at the port
  node and its current half a cell toward the line.
- Lumped and wire ports give identical S11 on the same cells.

### Completing a short record

A resonant structure can take far longer to ring down than you want to
simulate. For wire ports, `run(..., ringdown=RingdownSpec())` fits the
decaying tail of the record and adds the unrecorded part of each spectrum in
closed form:

```python
import numpy as np
from rfx.ringdown import RingdownSpec

MM = 1e-3
box = Simulation(freq_max=20e9, domain=(12 * MM, 11 * MM, 5 * MM), dx=1 * MM,
                 boundary="pec")
box.add_material("fill", eps_r=2.2, sigma=2 * np.pi * 12.5e9 * 8.854e-12 * 2.2 / 300)
box.add(Box((0, 0, 0), (12 * MM, 11 * MM, 5 * MM)), material="fill")
box.add_port((2 * MM, 2 * MM, 0.0), "ez", impedance=50.0, extent=1 * MM,
             waveform=GaussianPulse(f0=13e9, bandwidth=0.8, cutoff=4.5))

short = box.run(n_steps=1500, compute_s_params=True,
                s_param_freqs=np.linspace(8e9, 18e9, 101),
                ringdown=RingdownSpec())
print(short.ringdown.report.ok)          # did the completion pass its checks?
s11_completed = short.ringdown.s_params[0, 0, :]
```

`short.s_params` is still the plain, truncated result. The completed matrix is
`short.ringdown.s_params`, and `short.ringdown.report` lists the fitted poles
and the checks. `report.ok` is decided by comparing completions from two
different windows of the record. These checks catch a bad fit. They are not an
error bound.

`ringdown=` works with wire ports on a fixed-length record: one wire port on a
uniform mesh, and one or several on a graded mesh. Several wire ports on a
uniform mesh are refused: there `run()` builds S from one separate run per
driven port, while the completion fits the port records of the one run it is
given. Use a graded mesh, where one run fills the driven column. The source must be off in the
second half of the record. Lumped, microstrip, waveguide and coaxial ports,
TFSF, `until_decay` and `devices=` are refused.
`forward(..., ringdown=RingdownSpec())` puts the same completion inside the
differentiable program, so `jax.grad` sees the ringing too; it is also refused
with `distributed=True`.

### Ending a line at a port

When a trace runs to the edge of the domain, rfx extends it into the absorber,
as if the line continued forever. If the line is meant to end at your port,
name its conductor with `terminates=`:

```python
from rfx.mesh_edges import edge_aware_profiles

domain = (0.04, 0.02, 0.012)
strip = Box((0.0, 0.009, 0.006), (0.04, 0.011, 0.006))
line = Simulation(freq_max=6e9, domain=domain, dx=1e-3, boundary="cpml",
                  **edge_aware_profiles(domain, 1e-3, sheets=[strip],
                                        faces={"x": [0.035], "y": [0.010]}))
line.add_thin_conductor(Box((0.0, 0.0, 0.003), (0.04, 0.02, 0.003)))  # ground
line.add_thin_conductor(strip)
line.add_port((0.035, 0.010, 0.003), "ez", extent=3e-3,
              waveform=GaussianPulse(f0=3e9), terminates=strip)
```

Preflight takes a free sheet edge to lie 0.35 in-plane cell beyond the sheet's
last node, so the edge-aware mesh puts the 2 mm strip's last nodes 0.35 cell
inside its drawn edges. The 0.35 was measured where the cell normal to the
sheet is as long as the in-plane cell beside its edge. Here the z cell is 1 mm
and the in-plane cell beside each side edge 0.75 mm, a ratio of 1.33.
Interpolated between the ratios measured for a free sheet in vacuum (1.18 and
2, in [the accuracy notes](/rfx/check/model-on-grid/#accuracy)), the edge
would lie 0.43 cell beyond the last node, and the strip would be 2.12 mm wide
in vacuum. Three cells above a ground plane, as here, the offset at this ratio
has not been measured. Preflight uses 0.35 at every ratio, so it accepts this
strip; on a uniform 1 mm mesh it predicts 2.7 mm, and `run()` refuses the
strip.

Preflight warns (`port_conductor_continues`) when a port's conductor runs into
the absorber and no port terminates it. A ground plane should continue; name
only the line the port ends. Microstrip ports do this automatically for the
trace under them.

### Lumped circuit elements

`add_lumped_rlc` puts a resistor, inductor, capacitor or RLC combination on
one grid edge. It is **not a port**: it has no reference impedance. To measure
the reflection it presents, drive the line with `add_port(...)` and put the RLC
element on the line as the load, a cell or more from the port cell: on the port
cell it sits in parallel with the source, and S11 does not see it.

```python
sim.add_lumped_rlc((0.03, 0.02, 0.01), "ez", R=50.0, C=0.2e-12)
```

`topology` is `"series"` (default) or `"parallel"`. On the uniform,
single-device `forward()` path, `rlc_values_override={0: {"R": R}}` makes a
component value differentiable. The key is the element's registration order.

## Microstrip ports

`add_msl_port` spans the full width under the trace and extracts the line's
wave amplitudes from a row of probe planes downstream of the feed. Use
`compute_msl_s_matrix()`, not `run(compute_s_params=True)`:

```python
# Run from the repository root to use the tutorial's edge-aware board.
from examples.tutorials.ports_and_sparams_101 import build_microstrip_ports

board = build_microstrip_ports()
msl = board.compute_msl_s_matrix(freqs=np.linspace(2e9, 6e9, 13),
                                 num_periods=20)
print(np.abs(msl.S[1, 0]))     # |S21| across the band
```

On this board the edge-aware mesh puts the line's last nodes 0.35 cell inside
its drawn edges, and the z cell is 0.25 mm. Along the line the in-plane cell
beside each open end is also 0.25 mm, a ratio of 1, where the offset measured
for a free sheet in vacuum (0.35 to 0.36 cell) is the one preflight uses. Across
the line the cell beside each side edge is 0.2125 mm, a ratio of 1.18. For a
free sheet in vacuum the offset at that ratio was measured as 0.39 cell, so in
vacuum the line would be 1.015 to 1.018 mm wide (the range covers E
perpendicular and parallel to the edge). The line lies on the substrate's top
face, where the offset has not been measured.

`position` is `(feed plane, trace centre, substrate bottom)`. `direction` may
be `"+x"`, `"-x"`, `"+y"` or `"-y"`; the substrate normal is always z. `S` is
returned as extracted. A warning names any bins where it is not passive;
`enforce_passivity=True` projects it instead. `msl.reliable` flags bins with
too little signal to trust.

The builder in `examples/tutorials/ports_and_sparams_101.py` uses a
44 × 34 mm domain, edge-aware x/y profiles, and a uniform z profile of 16 cells of 0.25 mm. It
builds and preflights this board without solving it in the tutorial; the
calculation above runs it. This board is coarse for speed, so check `msl.Z0`,
the line impedance the port fits from its probe planes, against the
Hammerstad–Jensen closed form in `msl.line_impedances`.
S11 and S21 use the measured V and I, referred to each port's declared
`impedance=` (default 50 Ω); the fitted Z0 does not enter S. Refine before
you quote Z0.

Getting an accurate microstrip result:

- **The substrate sets the cell size.** On a thin substrate the substrate
  thickness binds long before the wavelength does. Preflight warns below 4
  cells through the substrate. Start there, then refine and check that your
  answer stops moving.
- **End the line at its ports, not in the absorber.** CPML is a much poorer
  termination for a two-conductor line than for a plane wave. Put a port at
  each end of the line.
- **Give the probes room.** The automatic probe offset and spacing are chosen
  in cells from the mesh under the port, and recounted at run time on graded
  or automatic meshes. On a short feed, rfx warns if there is no clean place
  for them. Check `msl.probe_clearance`, and lengthen the feed if it is
  insufficient.

## Waveguide ports

`add_waveguide_port` launches a TE or TM mode of a rectangular aperture and
decomposes the fields into that mode. Its aperture defines the guide, and
every aperture edge needs a conductor: draw PEC walls on the edges of a smaller
aperture, or a bare edge is refused. A port
that spans the whole cross-section uses the transverse domain faces as the
guide walls, so declare them PEC and put the absorber on the port axis only;
on a uniform mesh `boundary="cpml"` on every face is refused.

```python
guide = Simulation(freq_max=11e9, domain=(0.10, 0.023, 0.010), dx=1e-3,
                   boundary={"x": "cpml", "y": "pec", "z": "pec"}, cpml_layers=8)
guide.add_waveguide_port(0.01, mode=(1, 0), mode_type="TE", direction="+x",
                         f0=10e9, bandwidth=0.5, name="port1")
guide.add_waveguide_port(0.09, mode=(1, 0), mode_type="TE", direction="-x",
                         f0=10e9, bandwidth=0.5, name="port2")
print(guide.s_matrix_lane())
```

The 23 × 10 mm cross-section is 23 × 10 whole cells at 1 mm. A cross-section
between walls must be within 1 % of whole cells, or the default
`snap="strict"` refuses it and names a cell size that fits: a real WR-90,
22.86 × 10.16 mm, is refused at 1 mm and 2 mm and fits at 1.27 mm (see
[Boundaries](/rfx/model/boundaries/)). The port's section, from the cell just
behind its source through its reference plane, must hold one homogeneous, isotropic, lossless
medium: an empty guide, or a fill that spans it wall to wall, whose cutoff,
propagation constant and impedance the port then uses. Anything else there
(a partial or lossy fill, metal, a sheet, a lumped element, a design region)
is refused; start it beyond the reference plane.

Compute the matrix with `guide.compute_waveguide_s_matrix(normalize=...)`.
`waveform="differentiated_gaussian"` is refused on waveguide ports: its
zero-phase incident filter wraps the precursor to the end of the run and
re-injects it there. Use `waveform="modulated_gaussian"` (the default).
[Waveguide Ports](/rfx/guide/waveguide-ports/) covers normalization,
calibration planes and junctions.

## Coaxial ports

`add_coaxial_port(...)` builds a coax line, matched feed, TEM drive and voltage planes in experimental uniform single-device `run()` and `forward()`. `position` is the reference plane; `face="top"` or `"bottom"` selects the feed side and `pin_length` extends the pin toward the device. `run(compute_s_params=True, s_param_freqs=...)` and `forward(port_s11_freqs=...)` read S11 at that plane using the built line impedance, then renormalize it to `impedance`. The radii, `pin_length` and `impedance` are static declarations; PEC occupancy elsewhere can be differentiated. The coaxial calculators remain available with their own line layouts and limits.

Uniform mesh, one device, one coax port and no other S-port family; face top or bottom, float32, three-dimensional second-order Yee, CPML on all six faces, no periodic axis or TF/SF. The shell needs at least one whole cell from every lateral absorber, enough axial room for the line, and an NTFF box, when declared, containing the whole port. No conformal PEC, subpixel smoothing, eps_override or sigma_override.

Experimental uniform coax ports: same-line calculator equality, run()/forward() equality, bottom-feed, NTFF-leakage and occupancy-gradient checks define the validation scope; the antenna-level result against an independent solver is not yet shown.

The coaxial calculators build their own line: a coax along z with a matched
feed, a TEM source, and a row of probe planes. You register one
`add_coaxial_port` for the cross-section (its x/y centre, radii and
waveform) and call a calculator:

- `compute_coaxial_line_reflection(termination=...)`: one port. The line ends
  in a `"short"`, an `"open"` or a `"matched"` load; with `"matched"`,
  `dut_impedance=R` makes the load a resistor.
- `compute_coaxial_two_port()`: a through line with a port at each end.

```python
coax = Simulation(freq_max=40e9, domain=(0.008, 0.008, 0.040),
                  boundary="cpml", cpml_layers=8)
coax.add_coaxial_port((0.004, 0.004, 0.020), face="top",
                      pin_radius=0.635e-3, outer_radius=2.055e-3,
                      waveform=GaussianPulse(f0=8e9, bandwidth=1.2))

refl = coax.compute_coaxial_line_reflection(
    termination="short", n_steps=3000, freqs=np.linspace(4e9, 12e9, 5))
print(refl.status, f"{refl.annulus_cells:.1f} annulus cells")
print(np.abs(refl.s11))
```

The line's conductors are realized PEC. Their wall thickness is 1 mm, or the
room to the nearest absorber less one cell if that is smaller; a line with
less than a cell of room raises.

What the calculators need:

- A uniform, float32, 3-D Yee grid with CPML on all six faces. Exactly one
  coaxial port with `face="top"`, and nothing else in the model: no geometry,
  sheets, probes, monitors or other ports. The calculator refuses extras
  rather than ignoring them.
- The port's z position, `pin_length` and `impedance` do not place the line
  or set its loads. Use `feed_impedance=` and `dut_impedance=`.

Getting an accurate result:

- **Use at least 4 cells across the annulus** (between pin and outer
  conductor). Raise `freq_max` to shrink the cell. `status` reports
  `"under_resolved"` below about 3.5. The example above uses 3.8 for speed.
- **Keep the probe span physical.** Probe planes are placed in cells
  (`probe_start_cells`, `probe_spacing_cells`), so refining the mesh shortens
  the length the phase fit sees. Scale the spacing up when you refine.
- **Leave room around the line.** Both coax calculators absorb on all three
  axes, so an open end radiates instead of ringing in a closed can. A line
  whose outer wall comes within one cell of a lateral absorber is refused.

## Limits

- **Sources give no S-parameters.** `add_source`, polarized sources and TFSF
  have no impedance. Use a port and its calculator.
- **One port family per calculation.** Mixed lumped + microstrip is experimental.
  The coax-to-microstrip calculator is not supported (deprecated); removed after 2.3.
  Measure each line with its own calculator instead.
- **Circular polarization** from `add_polarized_source` is unverified.
- **Lumped/wire ports**: start from about 60 cells per wavelength; no current
  test measures S11's accuracy there, so a mesh series decides it.
  `forward(port_s11_freqs=...)` works on either mesh; over
  several devices see [Run on several devices](/rfx/run/multi-device/).
  Wire ports on a graded mesh are experimental.
- **Microstrip** `mode="eigenmode"` is unsupported. Graded-mesh microstrip has
  no external comparison yet. Subgridding and TFSF are refused.
- **Coax** calculators are checked on one
  geometry family, and only azimuthally symmetric discontinuities.
- **TFSF on a graded x axis:** normal incidence runs, with the incident line
  on the realized x cells; a closed box or an oblique wave there is refused.
- Detailed scope for every port family is in the
  [S-parameter section of the support matrix](https://github.com/bk-squared/rfx/blob/main/docs/guides/support_matrix.md#s-parameters).
