[Open the complete Python reference](/rfx/api/generated/rfx.html).

The reference includes the public `Simulation` builder, execution and measurement
methods, including methods inherited from internal mixins. Each build displays
its package version, documentation channel and source commit. The source links
point to that commit.

For an agent or a script, use the [typed API inventory](/rfx/api/inventory.json).
It includes parameter kinds, annotations, defaults, return annotations,
docstrings and source links. An absent annotation or reference link is represented
as `null`, rather than inferred.

Importable symbols are broader than the recommended workflows. Read the
[API guide](/rfx/api/) and [support boundaries](/rfx/api/support-boundaries/)
before selecting a source, port, mesh or observable.

[Machine-readable documentation](/rfx/api/machine-readable/) describes the
Markdown and JSON entry points.
