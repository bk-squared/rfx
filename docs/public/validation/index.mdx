This section collects the pages that tell you how far to trust an rfx result.
Start with the first one.

| Page | Read it when you want to know |
|---|---|
| [Cross-Validation and Accuracy](/rfx/guide/validation/) | how rfx is checked, and what you must check yourself before reporting a number |
| [Recommended Configuration](/rfx/validation/recommended-configuration/) | which setup to start from, and which calculator fits your port |
| [Support Boundaries](/rfx/api/support-boundaries/) | whether a feature or combination is supported, limited or refused |
| [Benchmarks](/rfx/guide/benchmarks/) | which cases compare rfx with another solver, and what they show |
| [Cross-Solver Validation](/rfx/validation/cross-solver/) | how to run a comparison script and read its result |

A plot, a Touchstone file or a report records what a run produced. It becomes
evidence only next to a closed-form result, an independent solver, a
measurement or a convergence study for the same setup.
