Use these scripts to reproduce a comparison for a specific RF configuration.
They are available in a source checkout and are not installed with the Python
wheel.

## Which script to run

The case list is [Benchmarks](/rfx/guide/benchmarks/): every script in
`validation/crossval/`, with its reference, its pass criterion and its reproduce
command, generated from `validation/crossval/manifest.json` and locked by a test.
This page covers only what running one of them means.

Run a script from the repository root, for example:

```bash
python validation/crossval/05_patch_antenna.py
```

An exit code of `0` means all configured checks passed. Exit code `1` means a
check failed. Exit code `2` means a required external solver or reference was
unavailable, so the comparison is inconclusive.

## Interpret the result

A comparison applies to the geometry, mesh, frequency range, source, port,
material model, boundary, and output used by that script. It is not a general
accuracy guarantee for related designs. Record those settings and the numerical
thresholds when citing a result. In a source checkout, `validation/README.md`
lists the remaining cavity, waveguide, material, and port checks.
