Agents should use auto-configuration as a starting point, not as a substitute
for RF judgement or support-matrix checks.

## Recommended sequence

1. Define the geometry, material, source/port family, and target frequency band.
2. Use `auto_configure(...)` or the high-level `Simulation(...)` builder to get
   a first mesh and time-step proposal.
3. Inspect preflight warnings and support-boundary status before running long
   jobs.
4. Run a short smoke simulation first.
5. Promote to a longer run only after the smoke output has sane field/probe
   amplitudes and the selected feature lane is documented.

The geometry planner returns an `offset`; add it to all drawn coordinates to
leave the planned margin below and above the board. A `Simulation(domain=...)`
without `dx` instead builds its auto mesh over the declared domain and keeps
the drawn coordinates. `body_flush_on_absorber` warns when a body's thin face
is flush with an absorber, which continues its material beyond that face.

## Gating on the preflight report

Read the gate off the report, never off its truthiness. `sim.preflight()`
returns a `PreflightReport`, which is a list of findings, so plain list
truthiness says the opposite of what a gate means: a clean report is EMPTY
and therefore falsy, while a report carrying nothing but advisories is
truthy. `if not sim.preflight(): raise ...` and `assert sim.preflight()`
both read as "stop unless this passed" and do the reverse — the assert
passes exactly when there are problems and fails on a clean run. Boolean
evaluation raises `TypeError` for that reason: the trap is loud at the call
site instead of a run that quietly skipped its own gate. Use
`report.raise_for_failure()` to stop on error-severity findings, `report.ok`
or `report.errors` for a condition, and `len(report)` when you mean "did
preflight find anything at all", which is the stricter gate that also
rejects advisories.

## Python sketch

```python
from rfx import Simulation, Box, GaussianPulse, auto_configure

geometry = [(Box((0.0, 0.0, 0.0), (0.08, 0.06, 0.0016)), "fr4")]
materials = {"fr4": {"eps_r": 4.4, "sigma": 0.025}}

config = auto_configure(
    geometry=geometry,
    materials=materials,
    freq_range=(1e9, 4e9),
    accuracy="standard",
)

sim = Simulation(**config.to_sim_kwargs())
sim.add_material("fr4", eps_r=4.4, sigma=0.025)
for shape, material in geometry:
    lo = tuple(v + d for v, d in zip(shape.corner_lo, config.offset))
    hi = tuple(v + d for v, d in zip(shape.corner_hi, config.offset))
    sim.add(Box(lo, hi), material=material)
position = tuple(v + d for v, d in zip((0.029, 0.03, 0.0008), config.offset))
sim.add_source(position, "ez", waveform=GaussianPulse(2.4e9, 0.8),
               amplitude_kind="current")
sim.add_probe(position, "ez")

result = sim.run(n_steps=min(config.n_steps, 200))  # smoke first; increase only after inspection
```

This smoke configuration emits preflight advisories about absorber thickness,
mesh grading and the absorber runway. A successful smoke run does not establish
that the proposed mesh is inside the validated envelope.

## What agents must report

- mesh/domain/frequency assumptions
- selected source or port family
- support status for each advanced feature
- smoke command and result artifact location
- whether any generated report, plot, or Touchstone file is derived from a
  supported, shadow, or experimental lane
