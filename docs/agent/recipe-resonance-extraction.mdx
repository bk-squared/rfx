A port-match dip and a modal resonance are different measurements. Use
`Result.find_resonances` for a source-off probe trace, and inspect its
frequency range and source-decay-time arguments in the API reference.
Use the [R/T recipe](./recipe-rt-measurement) for power spectra.

## Ringdown API controls

Import `RingdownSpec` and `gradient_witness` from `rfx.ringdown`;
`gradient_record_length_witness` is a top-level rfx export.

`run(ringdown=...)` and `forward(ringdown=...)` accept a `RingdownSpec`.
Use `RingdownSpec(identification_probes=...)` to declare identification
probes explicitly. `until_identified` is the identification-based stopping
control on `run`; read the method's supported-configuration checks before
combining it with other run options.

`gradient_witness` and `gradient_record_length_witness` are the user-facing
checks for a gradient workflow. Consult their current signatures and reported
verdicts rather than inferring validity from a successful run.

This recipe specifies API selection only. It does not supply device geometry,
a probe trace, or an executable simulation.
