# rfx Validation Scripts

These scripts compare rfx results with analytic calculations, other solvers,
or a second rfx configuration. They are test cases, not tutorials. Start with
`examples/README.md` if you are learning the software.

Each comparison covers the geometry, mesh, frequency range, source, and output
implemented by that script. A passing result does not establish accuracy for a
different setup.

## Run a validation case

Run scripts from the repository root. The straight-waveguide case is the
shortest place to start after completing the examples:

```bash
python validation/crossval/03_straight_waveguide_flux.py
```

The process exit code has a specific meaning:

- `0`: every configured numerical check passed, including a required external
  comparison when the case has one.
- `1`: a simulation, numerical check, or required execution step failed.
- `2`: the rfx checks completed, but a required reference file or external
  solver was unavailable. This result is inconclusive, not a pass.

See `crossval/manifest.json` for each script's dependencies, expected exit
codes, numerical-check files, and generated artifacts.

Patch-accuracy evidence lives in `tests/test_issue80_patch_resonance_harminv.py`, `tests/test_issue80_patch_s11_regression.py`, `tests/test_patch_cavity_eps_oracle.py`, and `tests/test_patch_canonical_farfield_e4.py` (committed thirds-rule OpenEMS far-field reference: directivity within 0.5 dB, resonance inside the documented −12% to −5% coarse-mesh band — a regression lock, not an accuracy statement). |

| `crossval/07_sheen_lpf.py` | Sheen 1990 stepped-impedance microstrip low-pass filter stopband | Characterization study, not an accuracy comparison. A committed Palace FEM referee shows the stopband is a double transmission zero (~7.0 and ~8.0 GHz) that OpenEMS reproduces to about 0.7%. The original rfx leg (num_periods=20, default probe offset) was non-passive (58/120 bins, worst column power 1794.5) and its argmin sat 9.6% from OpenEMS; the root cause — record truncation (settling witness −24.7 dB) plus probe near-field contamination — was measured and the leg regenerated 2026-07-26 (num_periods=60, witness −72 dB; n_probe_offset=30, which satisfies both the 5·h_sub near-field and the λ_g/4 reflector clearances; passivity-enforced `\|S\|` strictly ≤ 1 with the raw excess recorded per bin). The rfx argmin now lands at 7.874 GHz, the ~8 GHz doublet member, 1.4% from OpenEMS, and the re-derived referee shows rfx resolving both doublet members (structure distance 1.91% vs OpenEMS 0.66%; sides_with = openems stands). Read narrowly still: bins with `passivity_correction` > 0.05 (84/120, the dx=200 µm coarse-mesh envelope) remain artifact-class for magnitude claims, and the fitted passband `Re(Z₀)` reads ~67 Ω vs OpenEMS's flat ~51 Ω (printed, not gated — a low-frequency fit-conditioning artifact present at offset 30 and 40 alike; the in-band 5–15 GHz median is 49.8 Ω); the null position is insensitive to this. The checks lock the OpenEMS reference's soundness, the comparison shape, the committed null frequencies, the rfx passband mean, the referee verdict, and the evidence chain (strict bound, settling witness, correction footprint; fail-closed if a leg lacks the fields). |

Use `docs/guides/sparameter_support_matrix.md` for the supported range and authoritative checks. |
| `crossval/14_rect_cavity_pozar.py` | Rectangular air-filled PEC cavity eigenfrequencies | Exact closed-form Pozar cavity resonance, re-derived in the script; no external solver and no meshing tolerance enter the oracle. TE₁₀₁ is checked to 1% and at least one higher mode to 2%, for one 50×30×40 mm cavity on a dx = 1 mm mesh that divides all three extents exactly. The cavity is closed and lossless, so no settling witness applies and the harminv `Q` is a window-length artifact that is printed but not checked. Says nothing about open boundaries, lossy or dispersive fills, non-uniform meshes, or other geometries. |
| `crossval/15_patch_antenna_rt5880.py` | Probe-fed patch on a 3.175 mm RT/Duroid 5880 laminate, uniform mesh | A same-geometry rfx-versus-OpenEMS integration study on a different laminate from `crossval/05_patch_antenna.py`, which it does not replace. It checks a coarse-mesh envelope (resonance within 8% of the OpenEMS dip, a −40 dB settling witness, passivity on both sides, broadside directivity within 3 dB) and asserts the substrate rasterizes to exactly four cells before quoting a resonance. Patch accuracy is not established here; it remains delegated to `crossval/05_patch_antenna.py` and the committed tests that case names. |
| `crossval/16_pec_sphere_mie_ka_sweep.py` | PEC-sphere monostatic RCS vs exact Mie, ka 0.5–4.0 | Two-tier: coarse ka ≤ 1.25 and the fine rung at ka = 2.0 only are gated against a twice-re-implemented Mie series, at gate = round-up(measured clearance-scan envelope × 1.5) with the envelope population committed and recomputed by the gate test; coarse ka ≥ 1.5 and fine ka = 3.0/4.0 are reported but never gated — near the deep Mie nulls the monostatic value is domain-size unconverged (domain-to-domain spread 8.0 dB at coarse ka = 1.75 and 14.5 dB at fine ka = 3.0, worst single-point deviation 11.1 dB coarse / 9.3 dB fine; fine ka = 4.0 fails a 3.5 dB gate at 9 of 13 clearances in the committed anti-aliasing scan) and the minima positions move with domain size. Truncation (gated bins), domain and clearance witnesses are fixture data; the effective-radius and resolution-ladder probes are recorded as offline provenance, and incident leakage at the monostatic bin is excluded by the documented backscatter leakage null (the formerly-quoted sub-vs-unsub probe was retracted as a same-array tautology — `monostatic_rcs` is unsubtracted by construction). Says nothing about bistatic bins, dielectric spheres, or oblique incidence. |
| `crossval/17_dielectric_sphere_mie.py` | Lossless dielectric sphere (eps_r 2.56) monostatic RCS vs exact Mie, ka 0.5–2.5 | Material-path twin of the PEC ka-sweep; first cross-method record of the binary dielectric rasterize path (no sub-cell averaging exists — a staircase envelope, not a smooth-interface claim). Single gated tier: coarse ka ≤ 1.25 within 6.3 dB (committed 7-point clearance-scan envelope 4.18 dB × 1.5, round-up). No fine rung is gated — the committed cpr-12.8 witness scan shows doubled resolution does not buy a domain-robust tighter envelope (3.75/3.04 dB vs coarse 4.18). ka ≥ 1.5 is reported but never gated (domain-size-only spreads 11.7–29.0 dB). Says nothing about bistatic bins, lossy dielectrics, or smooth-interface accuracy. |
| `crossval/18_wr90_iris_modematch.py` | Single symmetric inductive iris in WR-90 vs a TEn0 mode-matching oracle, 8.2–12.4 GHz | First calibrated PEC-obstacle evidence in the rectangular-waveguide lane (multi-iris filters stay experimental — this is the prerequisite stage). Gated: fine rung dx = a/60 within 0.04 abs (envelope 0.0232 × 1.5) across eight configurations, plus a Richardson-extrapolation cross-check on the oracle within 0.01 abs at every fine/coarse pair; the first-order gap ratios (0.527–0.604) are the attribution witness. Coarse rung, raw extraction and residual ripple (measured against the oracle: fine ≤ 0.0077, coarse ≤ 0.0158) are reported but never gated. Three setup defects (parasitic wall-slot, half-ulp node-plane corners, an electrical aperture of d + 2·dx together with a too-thin absorber) were found and are each fenced; the earlier modal-extraction fence is retracted because its non-passivity evidence does not survive the corrected setup, with modal accuracy committed alongside (a little worse than flux, which keeps the gate). Says nothing about phase, multi-iris filters, posts, septa, or off-centre apertures. |
| `crossval/19_wr90_iris_filter_aghanim.py` | A published 4th-order WR-90 inductive-iris bandpass filter (five irises, four coupled cavities) vs a TEn0 mode-matching cascade oracle, 10.40–11.70 GHz | Diagnostic only — it reports a comparison and is not evidence for broader support. The reference HFSS/CST numbers are **digitized from the paper's figure**; no external solver is run here, and rfx is not compared against either commercial code. The first resonant multi-obstacle case in the rectangular-waveguide lane, where a per-face geometry error is a passband shift rather than a magnitude tolerance. Gated: centre frequency within 19 MHz (envelope 12.1230 × 1.5 over a nine-configuration population — four setup axes, each with an interior sample — spanning 0.06 MHz); the structural reflection-zero count, witnessed invariant across the 8.0–8.5-cell iris-thickness ambiguity band by a committed oracle-side sweep; and passband contiguity as a regression lock (span_holes ≤ 1), against the oracle on the as-realized geometry; measured +12.08 MHz, 3 zeros versus 3, one interior hole bin. A formulation-independent 2-D H-plane FDFD on the same electrical geometry (numpy/scipy only, Richardson over three refinement levels, two-estimate consistency 0.4 MHz — a same-model consistency check, not an error bound; the levels fit convergence order ≈1.25 rather than the assumed 1, worth ~0.7–1.0 MHz of order-assumption uncertainty) agrees with the mode-matching oracle to 1.1 MHz in f0 and 1.0 MHz in bandwidth, and rfx differs from both routes by the same amount — the residual sits on the FDTD side, is mesh-invariant when expressed in cells, and its origin is recorded as unattributed. Band edges and bandwidth are reported, not gated: the iris-thickness leg of the node-plane convention measures ≈(t−0.68)·dx and matches neither integer rule, leaving a half-cell comparator-input uncertainty that moves bandwidth ~40 MHz per cell against f0's ~2.4 MHz. Feeding the oracle the drawn cell counts instead of the realized ones biases f0 by 107.5 MHz — a bias the envelope×1.5 rule cannot catch, because that rule bounds scatter. Worst-case return loss, ripple levels, zero depths, contiguity detail beyond the span_holes lock, the coarse a/60 rung and phase are reported but never gated; ring-down settling, feed clearance and absorber depth are each held to one frequency bin. The built structure is a snapped version of the published filter (one of four structural zeros lost, worst return loss degraded 13.82 → 10.65 dB by rasterization alone). Says nothing about phase, group delay, loss, fabrication tolerance, arbitrary filters, posts or septa. |
| `crossval/20_msl_phase_referee.py` | MSL de-embedded phase (`angle(S21)`) vs an external OpenEMS referee, matched-mesh (`dx=50um`) RO4350B thru line | OpenEMS `MSL_NotchFilter.py` tutorial reproduce-gate plus a matched-mesh thru-line comparison against rfx's own `compute_msl_s_matrix`; resolves whether rfx's previously un-gated MSL phase was a time-convention or reference-plane mismatch (both tools' DFT kernels are identical at the source — it was reference-plane, resolved by matching the measurement plane to rfx's own probe-0 coordinate). Gated: each solver's own `angle(S21)` against its own measured `beta` (self-consistency) over 3.0–4.5 GHz. Reported, not gated: the raw cross-solver `angle(S21)` difference (≤1° in 22/30 bins, ≤0.304° in the gated band; the 500 MHz bin is excluded — the line is ~0.03 guide wavelengths there, where port extraction is ill-conditioned). The `CalcPort` reference-plane-referral rotation is unexercised on this fixture and untested off-grid. Applies to one geometry, one mesh, single drive. |
| `crossval/21_coax_two_port_referee.py` | Coax two-port through-line vs an external OpenEMS referee, matched-mesh (`dx=0.37474mm`) SMA-class PTFE coax (`a=0.635mm`, `b=2.055mm`, `L12=58.4595mm`) | OpenEMS `Coax.m` tutorial reproduce-gate (Stage A, against Coax.m's own closed-form line impedance) plus a matched-mesh `CoaxialPort` thru-line comparison against rfx's own `compute_coaxial_two_port` fixture (Stage B, two drives, full S-matrix) | Comparator-leg referee — brackets, does not judge rfx's own numbers; `compute_coaxial_two_port` itself remains EXPERIMENTAL. Gated: Stage A reproduces Coax.m's own ZL check (50.432 ohm vs analytic 49.940 ohm); Stage B gates each solver's own self-consistency — passivity, a matched-through magnitude band (gated central-band leg measured 0.9999966–1.0000282), and a phase/group-delay witness against the port's own measured `beta` (under it, phase deviation collapses from 111.38° to <0.44°; the gap is consistent with staircase dispersion on this fixture's coarse PTFE annulus, ~1.12x, but no mesh-refinement convergence witness has been run, and the four agreeing `beta` readings are one witness, not four — same run, same solver, same extractor). Reported, not gated: run-3's own `\|S21\|`~=1.000 across 4–12 GHz for this independent, differently-discretized geometry, and reciprocity (`\|S21\|` vs `\|S12\|`, essentially exact). Applies to one geometry, one mesh, two drives (forward + reverse). |

When reporting a result, include the script path, commit, geometry, mesh,
frequency range, comparator, and numerical thresholds. Do not generalize a
successful case to a different port, material model, boundary, or mesh without
an applicable comparison.

## Other validation directories

- `research/subgrid/12_subgrid_disjoint_prototype.py` is a short-duration
  research check for a topology that is not long-time energy-stable.
- `research/subgrid/13_subgrid_material_validation.py` demonstrates the guarded
  subgrid boundary and checks the same material setup on a uniform mesh.
  SBP-SAT/subgridding is not a supported feature.
- `tap_paper/` contains paper-support scripts. Values identified there as
  targets are experiment goals, not measured results. See
  `tap_paper/README.md` for the status of each script.
