# Vendored upstream tutorial: `bend-flux.py`

`bend-flux.py` in this directory is a **byte-for-byte, unmodified copy** of
Meep's own transmittance-spectrum tutorial script, fetched directly from
`NanoComp/meep` rather than transcribed by hand -- transcription is the
failure mode this vendoring avoids (cv01's own existing Meep comparator leg,
`validation/crossval/01_waveguide_bend.py:187-200`, is a hand-port that
diverged from this same tutorial in six of ten parameters; see the design
note this directory's `REPRODUCE_GATE_RECORD` links to).

- Upstream path: `python/examples/bend-flux.py`
- Repo: `NanoComp/meep`
- Fetched: 2026-09-10, via `gh api repos/NanoComp/meep/contents/python/examples/bend-flux.py`
- Git blob sha (upstream, as reported by the GitHub Contents API): `f56ab6492a3cc55ebc1fc0c682c4981508c51955`
- Verified byte-identical: `git hash-object validation/crossval/_01_waveguide_bend_upstream/bend-flux.py` returns the SAME sha, `f56ab6492a3cc55ebc1fc0c682c4981508c51955` -- this is not a claim, it is a reproducible check anyone can re-run.
- Referenced from Meep's own docs: `doc/docs/Python_Tutorials/Basics.md`, section "Transmittance Spectrum of a Waveguide Bend" (that markdown's own blob sha at fetch time: `f9c3d730dc31e4e52da6cefe191c3a8985ab5be4`).

## Do not edit this file

`bend-flux.py` must stay byte-identical to the upstream blob above. If Meep's
own tutorial changes upstream, re-fetch and re-record the new blob sha here
and in `REPRODUCE_GATE_RECORD` -- do not hand-patch it in place, and do not
add comments/headers to it (even a provenance comment inside the file would
make the "unmodified" claim unverifiable by simple hash comparison).

`scripts/diagnostics/waveguide_bend_tutorial_meep.py` is the separate,
NOT-vendored runner that executes this file (`exec()`, not a subprocess,
so it can read back the tutorial script's own module-level `wl`/`Rs`/`Ts`
arrays without the tutorial needing to save anything to disk itself) and
verifies its sha256/git-blob-sha before every run, refusing to proceed if
the vendored copy has drifted from what is recorded here.

## What the tutorial does NOT publish

Meep's own docs page for this example ends in `plt.show()` -- a plot,
`doc/docs/images/Tut-bend-flux.png`, not a printed number. There is no
upstream-published transmittance value this reproduce-gate can check
against. See `REPRODUCE_GATE_RECORD` for what it checks instead, and why
that is a weaker anchor than `validation/crossval/20_msl_phase_referee.py`'s
or `validation/crossval/21_coax_two_port_referee.py`'s (both check against a
number their own tutorial DOES publish).
