# Where the frozen references for the MSL open-stub notch filter come from

Facts only. Both files describe the same declared board: lossless εr = 3.66,
h_sub = 0.254 mm, trace and stub 0.6 mm wide, stub 12 mm, port-to-port line
5.0 mm, port margin 1.0 mm, box 7.0 × 16.232 × 1.754 mm, trace centre
y = 1.208 mm, stub centre x = 3.5 mm.

Neither file is re-generated by CI. The external solvers are run by hand, when
the case is created or its geometry changes.

## The two notch frequencies

Both estimates below are the vertex of a parabola fitted in dB through the
minimum bin and its two neighbours, except the openEMS "bin" row, which is the
bare argmin.

| record | notch (GHz) | depth (dB) | |S11| at the notch |
|---|---|---|---|
| openEMS dx 50 µm, bin argmin | 3.428571 | −41.293 | 0.9975 (−0.0219 dB) |
| openEMS dx 50 µm, parabolic | 3.426456 | −41.293 | — |
| Palace `coarse`, parabolic | 3.637065 | −37.338 | 0.827111 |
| Palace `mid`, parabolic | 3.631133 | −42.346 | 0.838567 |

Distance between the two solvers: Palace `mid` sits **5.908 %** above the
openEMS bin argmin, **5.973 %** above the openEMS parabolic estimate.

Palace's own mesh shift, `coarse` → `mid`: −0.005932 GHz, −0.163 %.
